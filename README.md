 Smart Healthcare Project Management and Monitoring System

 Project Overview
The Smart Healthcare Project Management and Monitoring System is a web-based application developed using the MERN stack. It is designed to help project managers monitor and manage a healthcare software development project involving multiple hospitals.

The system provides tools for project initiation, scope management, work breakdown structure (WBS), scheduling, resource allocation, cost estimation, Earned Value Management (EVM), quality assurance, risk management, change control, and progress reporting.

 Project Objectives
- Manage project information, objectives, scope, stakeholders, and baselines.
- Organize project requirements and tasks using a Work Breakdown Structure (WBS).
- Schedule activities and track task dependencies and delays.
- Monitor planned costs, actual costs, and project performance using EVM metrics.
- Track software defects, quality checks, and project risks.
- Record and evaluate change requests before including them in the approved scope.
- Generate project status and monitoring reports.

 Main Modules
1. Project Initiation and Integration
2. Scope Management and WBS
3. Schedule and Resource Management
4. Cost Management and Earned Value Management
5. Quality and Risk Management
6. Integration, Validation, and Reporting

 Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- API Communication: REST APIs

 Project Scenario
The system is designed around a healthcare software project serving five hospitals. The original project baseline is 16 weeks, with an approved budget of PKR 5,000,000.

A proposed AI-based preliminary diagnosis module and mobile application may increase the estimated budget by PKR 800,000 and extend the timeline by three weeks. The system is intended to help evaluate and monitor such changes against the approved project baseline.
